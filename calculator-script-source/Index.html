Новый противник

Показатели

Нужен только для просмотра вероятности сопротивления. Пустое поле использует типовой пул игрока выбранного уровня и не меняет сохранённый статблок.

Конструктор атак

По умолчанию у противника 2 атаки. Сильные противники получают больше вариантов, но в статблоке не может быть более 5 атак. Пул не включает Кубы сцены.

Конструктор реакций
